# **AirCars-Rental (12/8/2025)**

A full-stack app using Spring Boot, React, and PostgreSQL. Allows users to securely browse and list cars available for rent in a specified region.

## **Tech Stack Used** 
React, Vite, Tailwind, Spring Boot, PostgreSQL

## **Setup**

1. Install Node.js (v18+), npm/yarn, Java JDK 17+, Maven, PostgreSQL

2. Configure application.properties and front-end .env with GeoApify keys


## **What I have learned**
- Building backend services with Spring Boot
- Implementing secure authentication (JWT auth and cookies)
- Hashing and validating passwords
- Integrating external APIs for geolocation and autocomplete of addresses
- Gained hands-on experience with modular design, REST APIs, database design, and responsive UI
